# Case studies

Seven paper systems, CSTR control and battery voltage forecasting.

The [benchmark repository](https://github.com/SOULS-TAMU/daehn-benchmarks) supplies scripts, input data
and preserved models. Follow its general setup and each case's README before
running saved-model analysis. A short run tests execution; reproducing a paper
result also requires the recorded splits, architecture, losses, solver settings
and training horizon.

Keep new outputs separate from preserved checkpoints. See the
[migration guide](../MIGRATION.md) for historical saved-model formats.
